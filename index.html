Hoe werkt vrijewetgeving.nl? →

01

Elke wet een bestand

Alle Nederlandse wetten staan als Markdown-bestand in een open GitHub-repository. Leesbaar voor mens én machine.

02

Elke wijziging een commit

Verandert een wet? Dan is dat zichtbaar als een Git-commit. De volledige wetsgeschiedenis is doorzoekbaar.

03

Dagelijks bijgewerkt

Een geautomatiseerd script haalt elke dag nieuwe en gewijzigde wetten op van wetten.overheid.nl.

04

Iedereen kan bijdragen

Fout gevonden? Verbeteringsvoorstel? Open een Pull Request op GitHub. De wetgeving is van iedereen.

Waarom niet gewoon wetten.overheid.nl?

✓ Machine-leesbaar (Markdown) ✓ Versiegeschiedenis via Git ✓ Gratis te fork'en en hergebruiken ✓ Open API (JSON) ✗ wetten.overheid.nl: alleen HTML/PDF ✗ wetten.overheid.nl: geen open API
