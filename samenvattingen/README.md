# Samenvattingen in gewone taal

Elke wet kan een korte uitleg in begrijpelijke taal krijgen. Eén bestand per wet:

```
samenvattingen/<BWBR-nummer>.md
```

bijvoorbeeld `samenvattingen/BWBR0001854.md`.

## Richtlijnen
- Schrijf voor een gewone burger, geen jurist. Vermijd jargon of leg het uit.
- Kort: 2–5 alinea's. Wat regelt deze wet, voor wie, en wat betekent dat in de praktijk?
- Geen juridisch advies; beschrijvend, neutraal.
- Markdown mag (koppen, lijsten, vetgedrukt).
- Licentie: **CC BY-SA**. Door bij te dragen ga je hiermee akkoord.

De samenvatting verschijnt automatisch bovenaan de wet op vrijewetgeving.nl.
Een Pull Request openen kan direct via de knop "Schrijf een samenvatting" op de wet-pagina.
