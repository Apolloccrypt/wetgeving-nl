# Wetsvoorstellen

Deze map bevat community wetsvoorstellen ingediend via Pull Requests.

## Hoe werkt het?

1. Kopieer [`templates/voorstel-template.md`](templates/voorstel-template.md)
2. Sla op als `open/JAAR-jouw-beschrijving.md`
3. Dien een Pull Request in

## Status

| Status | Betekenis |
|--------|-----------|
| `open` | Actief in discussie |
| `in-behandeling` | Wordt serieus besproken |
| `aangenomen` | PR gemerged (community consensus) |
| `afgewezen` | Afgewezen na discussie |

---

*Voorstellen hier hebben geen officiële juridische status.*
