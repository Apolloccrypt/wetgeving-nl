# Beveiligingsbeleid

## Fouten in wetteksten

Staat er een inhoudelijke fout in een wettekst (tekst klopt niet met de
officiele versie op wetten.overheid.nl)?

Open een Issue met het template "Fout in een wet".

## Beveiligingsproblemen in de scripts

Heb je een kwetsbaarheid gevonden in de scripts of workflows?

Meld dit niet via een publiek Issue, maar stuur een e-mail of gebruik
GitHub's "Report a vulnerability" functie onder het Security-tabblad.

## Scope

Dit project beheert alleen wetteksten en conversie-scripts.
Het slaat geen gebruikersdata op en heeft geen login-systeem.
Het aanvalsoppervlak is beperkt tot de GitHub Actions workflows.
