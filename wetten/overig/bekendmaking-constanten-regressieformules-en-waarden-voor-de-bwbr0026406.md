# Bekendmaking constanten regressieformules en waarden voor de gemiddelde CO2-uitstoot voor benzine- en dieselauto's 2010

##### artikel Enig

De constanten voor de in [bijlage 4 bij het Besluit etikettering energiegebruik personenauto's](https://wetten.overheid.nl/jci1.3:c:BWBR0011761&bijlage=4) opgenomen regressieformules, en de daarbij behorende waarden van de gemiddelde CO2-uitstoot voor personenauto's met benzine als brandstof, en voor personenauto's met diesel als brandstof, voor het kalenderjaar 2010, als volgt vast te stellen:

SET 1.

Constanten berekend op basis van de huidige wetgeving

| C1, lengte: | 3,874 |
| --- | --- |
| C2, lengte: | –4,396 |
| C3, lengte: | 2,619 |

| C1, benzine: | 45,809 |
| --- | --- |
| C2, benzine: | 3,618 |
| C3, benzine: | 1,454 |

| C1, diesel: | –5,875 |
| --- | --- |
| C2, diesel: | 11,059 |
| C3, diesel: | 0,868 |

| Gemiddelde CO2-uitstoot benzine: | 145,3 |
| --- | --- |
| Gemiddelde CO2-uitstoot diesel: | 148,9 |

Constanten voor 2010 en 2011, berekend door het Ministerie van VROM op basis van nieuwe concept-regelgeving

| C1, lengte: | –1,2412 |
| --- | --- |
| C2, lengte: | 1,7737 |
| C3, lengte: | 0,7693 |

| C1, benzine: | 166,3563 |
| --- | --- |
| C2, benzine: | –29,8404 |
| C3, benzine: | 3,9167 |

| C1, diesel: | 344,5974 |
| --- | --- |
| C2, diesel: | –78,3711 |
| C3, diesel: | 6,7313 |

| Gemiddelde CO2-uitstoot benzine: | 163,2320 |
| --- | --- |
| Gemiddelde CO2-uitstoot diesel: | 135,7337 |
