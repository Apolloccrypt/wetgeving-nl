# Besluit SONT tarieven en voorwerpen thuiskopievergoeding 2027–2028

| Voorwerp | tarief 2027–2028 |
| --- | --- |
| PC/laptop/server | € 4,00 |
| externe HDD | € 2,10 |
| tablet | € 2,50 |
| e-reader met > 16GB opslagruimte | € 7,80 |
| e-reader met ≤ 16GB opslagruimte | € 3,90 |
| smartphone | € 3,80 |
| AV-speler | € 6,00 |
| NAS | € 4,00 |
| USB | € 0,80 |
| smartwatch | € 0,40 |

Voor refurbished voorwerpen die door een onderneming worden aangeboden aan eindgebruikers geldt, zoals in voorgaande jaren, een tarief dat met 40% verlaagd is ten opzichte van het tarief in de tabel. Voor refurbished voorwerpen wordt rekening gehouden met de verwachte kortere levensduur.
