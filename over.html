Over vrijewetgeving.nl

Alle Nederlandse wetgeving als open, machine-leesbare data — gratis, doorzoekbaar en met volledige versiegeschiedenis. Direct zoeken →

Hoe werkt het? →

01

Elke wet een bestand

Alle Nederlandse wetten staan als Markdown-bestand in een open GitHub-repository. Leesbaar voor mens én machine.

02

Elke wijziging een commit

Verandert een wet? Dan is dat zichtbaar als een Git-commit. De volledige wetsgeschiedenis is doorzoekbaar.

03

Dagelijks bijgewerkt

Een geautomatiseerd script haalt elke dag nieuwe en gewijzigde wetten op van wetten.overheid.nl.

04

Iedereen kan bijdragen

Fout gevonden? Verbeteringsvoorstel? Open een Pull Request op GitHub. De wetgeving is van iedereen.

Waarom niet gewoon wetten.overheid.nl?

✓ Machine-leesbaar (Markdown) ✓ Versiegeschiedenis via Git ✓ Gratis te fork'en en hergebruiken ✓ Open data (JSON) ✗ wetten.overheid.nl: alleen HTML/PDF ✗ wetten.overheid.nl: geen open API

Bron & licentie

De wetteksten komen van het Basis Wetten Bestand (BWB) via wetten.overheid.nl / data.overheid.nl. Wetgeving is publiek domein: de teksten staan onder CC0. De code van deze site staat onder de MIT-licentie. Je mag alles vrij hergebruiken, ook commercieel.

Open data & API

De data is gewoon een set statische JSON-bestanden die je direct kunt ophalen:

  • /index.json — alle wetten met titel, identifier, categorie, soort, datum en status.
  • /verwijzingen.json — graaf van kruisverwijzingen tussen wetten.
  • /zoekindex.json — doorzoekbare wettekst (titel + eerste 2.000 tekens).

Een afzonderlijke wet als Markdown staat op github.com/Apolloccrypt/wetgeving-nl onder /wetten/<categorie>/.
